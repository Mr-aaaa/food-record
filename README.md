# 每日营养

每日营养是一个本地优先的食物热量与营养记录工具。它支持设置每日目标、记录实际或计划餐食、生成可复制到第三方 AI 的餐食分析提示词、导入结构化餐食结果、保存餐食模板、追踪体重与腰围，以及完整备份和恢复浏览器中的数据。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

开发服务器启动后，打开终端输出的本地地址。

## 验证

```bash
npm test -- --run
npm run build
```

## 数据与隐私

- 应用没有账号或云端同步功能，数据仅保存在当前浏览器的 IndexedDB 中。
- 清除站点数据、使用新的浏览器配置或更换设备，都可能导致无法访问原数据。
- “Download full backup” 会导出一份包含全部本地记录的 JSON 文件。请将其妥善保管；恢复时可选择合并或替换当前数据。
- 备份可能包含饮食、营养目标、体重和腰围等敏感信息，不应上传到不受信任的服务。
- 应用只生成可复制的餐食分析提示词，不会自行把内容发送给 AI。将提示词或餐食信息粘贴到第三方 AI 服务时，该服务的隐私政策和数据处理条款适用。

## P0 范围

当前版本包含：

- 目标设置与内置饮食方案
- 实际和计划餐食记录及每日营养汇总
- 便携提示词生成、JSON 校验和餐食确认
- 餐食模板保存与应用
- 体重、腰围及基础趋势
- 完整数据导出、合并恢复和替换恢复
- 桌面与移动端响应式界面和基础无障碍支持

当前版本不包含账号、云同步、多人协作、营养师或医疗建议、第三方 AI API 直连、图片识别、条码扫描、设备间自动同步或原生移动应用。
